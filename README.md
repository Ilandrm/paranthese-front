# Parenthèse Enchantée - Site Web

Un site web moderne et élégant pour Parenthèse Enchantée, centre de séminaires bien-être.

## 🌟 Fonctionnalités

- **Design moderne et responsive** avec Tailwind CSS
- **Navigation intuitive** avec menu mobile
- **Pages complètes** : Accueil, Séminaires, Hébergement, À propos, Contact
- **Formulaire de contact** interactif
- **Optimisé pour le SEO** avec meta tags appropriés
- **Accessibilité** respectée
- **Performance optimisée** pour le web

## 🎨 Design

- **Palette de couleurs** : Tons verts apaisants (emerald) avec accents naturels
- **Typographie** : Inter pour le texte, Playfair Display pour les titres
- **Style** : Moderne, épuré, professionnel
- **Icônes** : Heroicons pour une cohérence visuelle

## 🚀 Technologies

- **Nuxt 3** - Framework Vue.js full-stack
- **Vue 3** - Framework JavaScript réactif
- **Tailwind CSS** - Framework CSS utilitaire
- **TypeScript** - Typage statique
- **Heroicons** - Icônes SVG

## 📦 Installation

```bash
# Cloner le repository
git clone git@github.com:Ilandrm/paranthese-front.git

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

## 🛠️ Scripts disponibles

```bash
# Développement
npm run dev

# Build de production
npm run build

# Génération statique
npm run generate

# Prévisualisation
npm run preview

# Déploiement sur GitHub Pages
npm run deploy
```

## 📱 Pages

- **Accueil** (`/`) - Présentation générale et services
- **Séminaires** (`/seminaires`) - Détails des offres collectives et individuelles
- **Hébergement** (`/hebergement`) - Informations sur l'hébergement
- **À propos** (`/a-propos`) - Histoire, philosophie et équipe
- **Contact** (`/contact`) - Formulaire et coordonnées
- **Mentions légales** (`/mentions-legales`) - Informations juridiques
